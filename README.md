# TurretForge

Мобильная игра для Telegram Mini App: объединяйте турели и защищайте базу от волн врагов.

## Играть

https://TimurMozgo.github.io/TurretForge/

## Возможности

- 20 уровней турелей и 15 анимированных видов врагов.
- Слияние касаниями и перетаскиванием, автоматическая стрельба, броня, боссы и импульс.
- Поле на весь экран и адаптивное управление.
- Меню паузы со звуком и перезапуском; закрытие крестиком, свайпом вниз или касанием вне окна.
- Локальное сохранение прогресса на устройстве.
- Telegram Web App SDK и поддержка обычного браузера.

## Разработка

Откройте `index.html` в браузере либо запустите любой статический HTTP-сервер в корне проекта.
Сборка и установка зависимостей не требуются. Исходники: `game.js`, `style.css`, `index.html`.
GitHub Pages публикует корень ветки `main`.

## Ресурсы

Графика из предоставленного CraftPix Idle Turret Defense Asset Kit. Условия: [CraftPix](https://craftpix.net/file-licenses/), также `ASSET-LICENSE.txt`.
Звуки победы и поражения предоставлены владельцем проекта. Остальные эффекты синтезируются через Web Audio API.

Прогресс хранится в localStorage текущего браузера. При повторном открытии текущая волна начинается заново. Серверная авторизация, синхронизация прогресса и подключение к конкретному боту не входят в эту версию.
